| Termo                      | Significado                                                                                                                 |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Portaria MTP 671/2021**  | Norma do Ministério do Trabalho e Previdência que disciplina o controle de jornada e os registradores eletrônicos de ponto. |
| **REP-P**                  | Registrador Eletrônico de Ponto via Programa: o próprio software é o registrador (art. 78). Este sistema opera como REP-P.  |
| **PTRP**                   | Programa de Tratamento de Registro de Ponto: trata as marcações e gera relatórios (AEJ).                                    |
| **NSR**                    | Número Sequencial de Registro: contador único, sem lacunas, de marcações e eventos do REP.                                  |
| **AFD**                    | Arquivo Fonte de Dados: exportação fiscal do livro do REP (marcações originais e eventos).                                  |
| **AEJ**                    | Arquivo Eletrônico de Jornada: exportação fiscal do ponto **tratado** (jornadas, marcações incluídas/desconsideradas).      |
| **Atestado Técnico**       | Declaração de conformidade do programa (art. 89), assinada com e-CPF do responsável.                                        |
| **INPI**                   | Instituto Nacional da Propriedade Industrial, onde se registra o programa de computador (art. 91).                          |
| **ICP-Brasil / e-CNPJ A1** | Infraestrutura de chaves públicas e certificado institucional usado para selar PDFs (PAdES) e arquivos (CAdES).             |
| **PAdES / CAdES**          | Formatos de assinatura digital para PDF e para arquivos em geral.                                                           |
| **Espelho de Ponto**       | Folha mensal de ponto gerada pelo sistema, assinada pelo funcionário e pelo chefe.                                          |
| **Quadro / Assinatura**    | Registro (`AssinaturaQuadro`) do processo de assinatura do Espelho do mês.                                                  |
| **Ciclo**                  | Período do banco de horas entre dois marcos de fechamento.                                                                  |
| **Marco**                  | Data (dia/mês) de fechamento do ciclo do banco de horas.                                                                    |
| **Zeragem**                | Encerramento do ciclo: o saldo é tratado conforme a regra e o banco recomeça.                                               |
| **Liberação**              | Tempo do banco que o RH libera ao funcionário para usar em abono, com validade.                                             |
| **ACT**                    | Acordo Coletivo de Trabalho (ex.: ACT 2026-2028, jornada de 7 h/dia).                                                       |
| **DSR**                    | Descanso semanal remunerado.                                                                                                |
| **Interjornada**           | Descanso mínimo entre o fim de uma jornada e o início da seguinte (CLT art. 66: 11 h).                                      |
| **SSO**                    | Login único via Keycloak (OpenID Connect).                                                                                  |
| **JWT / JWKS**             | Token de acesso assinado e o conjunto de chaves públicas usado para validá-lo.                                              |
| **Super Admin**            | Administrador máximo do sistema.                                                                                            |
| **Start**                  | Marco de entrada em produção (mês de go-live) do sistema.                                                                   |
| **Instância**              | Identidade da VM/instalação que grava no livro do REP (usada para detectar segunda instância ativa).                        |
