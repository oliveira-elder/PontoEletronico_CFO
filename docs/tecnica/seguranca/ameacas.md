## Achados e situação

Achados identificados na revisão desta documentação e o que foi feito.

| #      | Achado                                                                                             | Situação                                                                                                                                                                                                                                                                                              |
| ------ | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A1** | `/uploads/**` era servido sem autenticação.                                                        | **Corrigido.** Só é entregue com link assinado (HMAC do caminho + validade de 12 h), emitido nas respostas da API a quem tem permissão; sem assinatura válida responde 403. O banco guarda o caminho simples (a assinatura é removida na entrada). Chave: `UPLOADS_SIGN_SECRET` ou `DOC_SEAL_SECRET`. |
| **A2** | Controladores herdados do MVP sem autenticação (`/content`, `/modules`, `/org`, `/chat`, `/glpi`). | **Corrigido.** Exigem login; as escritas exigem `ponto-admin` (ou Super Admin).                                                                                                                                                                                                                       |
| **A3** | Sem limitador de taxa.                                                                             | **Mitigado no nginx**: 30 req/s por IP na API (rajada de 120) e 5 req/s (rajada de 15) na verificação pública; excesso responde 429.                                                                                                                                                                  |
| **A4** | Tokens HS256 aceitos com `JWT_SECRET` padrão conhecido (qualquer pessoa poderia forjar um token).  | **Corrigido.** HS256 só com `ALLOW_DEV_TOKENS=true`, fora de produção e com `JWT_SECRET` diferente do padrão. O login de desenvolvimento exige essa liberação. **Trocar `JWT_SECRET` por um valor forte continua recomendado.**                                                                       |
| **A5** | Sem cabeçalhos de segurança.                                                                       | **Parcial.** nginx envia HSTS, `X-Content-Type-Options`, `X-Frame-Options` e `Referrer-Policy`; a API envia `nosniff`. **CSP não foi aplicada** (estilos inline do front e Keycloak embutido exigem ajuste fino).                                                                                     |
| **A6** | Token na URL.                                                                                      | **Corrigido.** `?access_token=` só vale para `/logs/stream` (SSE não envia cabeçalhos); os demais downloads usam o cabeçalho `Authorization`.                                                                                                                                                         |
| **A7** | Alta disponibilidade (banco único).                                                                | **Pendente** — é infraestrutura (replicação/VM redundante), não de código.                                                                                                                                                                                                                            |
| **A8** | Sem retenção do `AuditLog`.                                                                        | **Opcional implementado.** Com `AUDIT_LOG_RETENTION_DAYS` (mínimo 365) a rotina diária das 03:30 apaga registros mais antigos; sem a variável, nada é apagado — a política de retenção deve ser decidida pelo CFO.                                                                                    |
